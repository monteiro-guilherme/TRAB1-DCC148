# Double Bragon — Protótipo Beat 'em Up

Protótipo acadêmico de jogo de ação 2D inspirado nos clássicos *beat 'em up*, desenvolvido com **Godot 4** e **GDScript**.

O jogador controla uma protagonista que precisa atravessar uma fase urbana, enfrentar inimigos e alcançar o lado direito do mapa.

## Controles

| Ação | Tecla |
|---|---|
| Movimentar para cima | ↑ |
| Movimentar para baixo | ↓ |
| Movimentar para esquerda | ← |
| Movimentar para direita | → |
| Soco | z |
| Chute | x |
| Ataque especial (taco) | c | (condição: necessário 3 socos para poder usar o taco)

As teclas de ataque devem corresponder às configurações do Input Map do projeto.

## Objetivo do jogo

Atravesse a fase enfrentando os inimigos e tentando sobreviver até chegar ao final do cenário.

**Condição de vitória:** alcançar o lado direito do mapa, encostando na parede de saída.

**Condição de derrota:** perder todos os pontos de vida da protagonista.

Na versão atual, o jogo é encerrado quando uma dessas condições é atingida.

## Inimigos

**Bancho:** inimigo que observa, persegue, ataca e recua para preparar novos golpes.

**Brute:** inimigo mais resistente e agressivo, que persegue continuamente e utiliza ataques aleatórios.

## Como executar

### Pela Godot

1. Instale a Godot 4.
2. Baixe ou clone o repositório.
3. Importe o arquivo `project.godot`.
4. Execute o projeto pressionando F5.

### No Windows

1. Baixe o jogo pela seção Releases do GitHub.
2. Extraia o arquivo ZIP.
3. Execute `DoubleBragon.exe`.
